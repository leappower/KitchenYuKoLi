# 餐饮门店解决方案

> 🔄 最后更新：2026年4月

---

## 适用场景

日出餐 **100-500份** 的外卖品牌、快餐连锁、小食店、中餐厅、特色餐饮等。

## 客户痛点

| 痛点 | 具体表现 |
|------|---------|
| 出品不稳定 | 依赖厨师水平，不同人做出来的菜味道不同 |
| 人力成本高 | 厨师月薪8000-15000元，且难招难留 |
| 扩张瓶颈 | 新开店需要重新培养厨师，标准化难以复制 |
| 空间有限 | 小厨房空间需要高效利用 |
| 合规压力 | 油烟排放、消防安全等监管要求 |

## YuKoLi方案

### 标准配置清单

| 设备 | 数量 | 用途 | 预算参考 |
|------|------|------|---------|
| 台式自动炒菜机 | 2-3台 | 炒菜、炒饭、炒粉 | 主力设备 |
| 商用电磁炉 | 1-2台 | 辅助加热、煮制 | 配套 |
| 油烟净化设备 | 1套 | 排烟净化 | 必配 |
| 自动洗碗机 | 1台 | 餐具清洁 | 配套 |

### 人员配置
- **传统厨房**：3-5名厨师 + 2名帮厨
- **YuKoLi厨房**：1名厨工即可操作全部设备
- **年省人工成本**：约20-60万元

### 场地要求
- 厨房面积：**15-30㎡**
- 电功率需求：约**20-40kW**（380V三相电）

## 核心优势

1. **出品一致性**：菜谱容量100+到800+道，每道菜温度曲线、翻炒速度、加料时间全部标准化固化
2. **爆炒能力**：瞬间升温300°C，保留"锅气"，满足川湘粤菜爆炒需求
3. **人员精简**：1名厨工替代2-5名厨师
4. **节能环保**：电磁热效率≥90%，比燃气省60%燃料费
5. **快速扩张**：新店只需培训厨工操作机器，无需培养厨师

## 投资回报

| 成本项目 | 传统厨房 | YuKoLi厨房 | 年节省 |
|---------|---------|-----------|--------|
| 人工成本 | 3名厨师×12万/年=36万 | 1名厨工×6万/年=6万 | **30万/年** |
| 能源成本 | 燃气费约8万/年 | 电磁约3万/年 | **5万/年** |
| 水费 | 炉体冷却约1万/年 | 不需水冷 | **1万/年** |
| **合计** | | | **36万+/年** |

> 💡 **回收期**：快餐店（2-3台台式机）约 **6-12个月** 回收投资
