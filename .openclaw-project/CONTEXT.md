# KitchenYuKoLi 官网项目

## 项目背景
YuKoLi 智能厨房设备官网，面向 B 端客户（餐饮企业、经销商）展示产品、解决方案、服务等内容。

## 用户偏好
- **设计风格**：洁白干净，不喜陈旧/发黄调
- **品牌理念**：设备帮用户成长，工厂和用户/代理共同成长，长期互盈（双受众：买家+经销商）
- **售后理念**：不是「远程优先」也不是「上门优先」，而是「快速响应→精准定位问题→对症下药给出最快方案」（远程/寄配件/上门，哪个快用哪个）
